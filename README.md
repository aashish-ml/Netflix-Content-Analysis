## 🎬 Netflix Content Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on Netflix's movies and TV shows dataset.

The objective is to analyze Netflix's content library and identify meaningful trends related to content type, genres, ratings, countries, release years, and content growth.

The analysis was performed using Python, Pandas, Matplotlib, and Seaborn.

---

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows on Netflix.
- Identify the most common content genres.
- Analyze content ratings and audience categories.
- Explore Netflix content growth over the years.
- Identify countries producing the most Netflix content.
- Analyze the distribution of release years.
- Generate business insights from the data.

## 📂 Dataset

The dataset used in this project contains information about Netflix movies and TV shows.

### Dataset Features

| Column | Description |
|---|---|
| `Show Id` | Unique ID assigned to each title |
| `Content Type` | Type of content: Movie or TV Show |
| `Title` | Name of the movie or TV show |
| `Director` | Director of the content |
| `Cast` | Main cast members |
| `Production Country` | Country where the content was produced |
| `Date Added` | Date when the content was added to Netflix |
| `Release Date` | Original release year of the content |
| `Rating` | Content rating |
| `Duration` | Movie duration or number of seasons |
| `Genres` | Genre or category of the content |
| `Description` | Short description of the content |

### Dataset File

The dataset is available in the project repository as:

`netflix_titles.csv`

The dataset is loaded and analyzed using Python and Pandas in the Jupyter Notebook.

## 💡 Key Insights

The analysis of the Netflix dataset provides the following key insights:

- Netflix contains a large number of Movies as well as TV Shows.
- Movies represent a significant portion of the total Netflix content.
- Drama, International Movies, and Comedy are among the commonly appearing content genres.
- Netflix offers content across a wide range of ratings suitable for different audience groups.
- The United States and other major content-producing countries contribute a large share of Netflix titles.
- Netflix content has increased significantly over the years, showing strong platform growth.
- A large portion of the available content was released in recent years.
- The dataset shows changing trends in content production and distribution over time.

### 📌 Overall Finding

The analysis indicates that Netflix has built a diverse content library covering different genres, countries, ratings, and content types. The data can help identify content trends and support better content strategy and business decisions.
